02 / RESEARCH NOTE

Measure the model.
Question the result.

My independent study investigated whether language models can consistently identify vulnerable code. The benchmark makes failure modes visible—not just headline accuracy.

Read the research case study ↗
01 / METHODOLOGY3 models × 3 prompting approaches

Zero-shot, few-shot, and CWE-reference context tested with reproducible sample sets.

02 / OBSERVATIONMore context ≠ better detection

Prompting strategies had model-specific effects; added reference material did not consistently help.

03 / LIMITATIONCWE classification was difficult

Correctly naming a weakness type proved harder than binary vulnerability identification.
